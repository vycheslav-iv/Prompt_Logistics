# Prompt Logistics

Две ноды для сборки промпта и маршрута «промпт → LLM → итоговый промпт»
в ComfyUI (Nodes 2.0). Все пять переключателей — на первой ноде; вторая
настроек не имеет.

## Зачем две ноды

ComfyUI не пропускает цикл «нода → LLM → та же нода» (HTTP 400,
`dependency_cycle`). Поэтому маршрут разорван на две ноды, провода идут
только вперёд:

```
Основной промпт ──> Prompt logistics ──> Промпт в LLM ──> LLM
Мастер-стиль ────>│   sys prompt mod         │
Дополн. промпт ──>│   sys prompt plus        │
                  │   sys use LLM            │
                  v                          v
           Prompt logistics — SYS <──────────┘
                  │
                  v
             Итоговый промпт ──> CLIP Text Encode
```

## Prompt logistics — все настройки здесь

Входы: `Основной промпт`, `Мастер-стиль`, `Дополн. промпт` (все необязательные).
Переключатели: `LLM промпт: вкл`, `Мастер-стиль: вкл`, `Мастер-стиль в LLM: вкл`, `Дополн. промпт: вкл`, `Дополн. промпт в LLM: вкл`.
Выходы (в этом порядке): `Промпт в LLM`, `sys prompt mod`, `sys prompt plus`, `sys use LLM`.

- `Дополн. промпт в LLM: вкл` работает только при включённом `Дополн. промпт: вкл`; при выключенном
  `Дополн. промпт: вкл` дополнительный промпт не участвует нигде.
- `Мастер-стиль` — главный выключатель стиля, `Мастер-стиль в LLM: вкл` — только маршрут.
  `Мастер-стиль: вкл` OFF → `Мастер-стиль` не идёт ни в LLM, ни в итог, даже если
  `Мастер-стиль в LLM: вкл` включён. `Мастер-стиль: вкл` ON: `Мастер-стиль в LLM: вкл` ON → `Мастер-стиль` в
  `Промпт в LLM`, `Мастер-стиль в LLM: вкл` OFF → `Мастер-стиль` добавляется к итогу после LLM.
  Дубля нет ни в одном режиме.

## Prompt logistics — SYS — без настроек

Входы: `Промпт из LLM` (результат LLM), `sys prompt mod`, `sys prompt plus`,
`sys use LLM` — все четыре подключаются к выходам первой ноды.
Выход: `Итоговый промпт`.

- `sys use LLM` OFF — берётся прямой промпт.
- `sys use LLM` ON — берётся `Промпт из LLM` плюс `sys prompt plus`; пустой результат **не**
  заменяется исходным промптом.
- `sys prompt plus` содержит `Дополн. промпт` (если `Дополн. промпт: вкл` включён, а `Дополн. промпт в LLM: вкл` нет)
  и `Мастер-стиль` (если `Мастер-стиль: вкл` включён, а `Мастер-стиль в LLM: вкл` нет).

## LLM не запускается зря

Вход `Промпт из LLM` — ленивый (`lazy` + `check_lazy_status`). Пока `LLM промпт: вкл`
выключен, ComfyUI не запрашивает ветку LLM: Ollama не выполняется даже на
первом прогоне (кэш для этого не нужен). Это тот же результат, что даёт
`ComfySwitchNode` в рабочей схеме, но без третьей ноды.

## Правила склейки

Части не изменяются; пустые пропускаются; между частями ровно один пробел;
служебные подписи в промпт не попадают.

## Установка

```bash
python sync.py Prompt_Logistics
```

Затем перезапустить ComfyUI и обновить страницу (Ctrl+F5).
