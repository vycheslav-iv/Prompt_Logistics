## 3. Проблемы, которые встречались (и как решали)
- Аудит переключателей держал `count === 1` для подписей — после переименования
  «Мастер-стиль» и «Дополн. промпт» встречаются дважды (вход + переключатель).
  Лечение: срез `togBlock` + проверка позиций по порядку + `>= 1`.
- Грубая замена в доках оставила bare `INT` в таблице истинности; таблица
  переписана целиком (`Осн`/`Доп`/`Мастер`/`LLM` + строка «Обозначения»).
- heredoc в git-bash схлопывает `\` → блоки с regex и `\n` править только
  edit-tool; `py_compile` создаёт `__pycache__` — удалять перед аудитом.

## 4. Что важно не сломать
- Цикл `S → LLM → S` невозможен (`dependency_cycle`, HTTP 400): разрыв — нода F.
- `style_prompt`/`use_int` — главные выключатели; `style_in_llm`/`int_in_llm` —
  только маршруты; `suffix` никогда не содержит часть, ушедшую в LLM.
- `sys prompt mod` всегда содержит дополн. промпт при включённом выключателе
  (дубля в итоге нет: прямой выход используется только при `LLM промпт` OFF).
- `check_lazy_status` обязан молчать без реальной связи `[id, slot]`.
- Keys входов (`prompt`/`master`/`int_prompt`/…) не менялись — старые воркфлоу
  по подписям не ломаются, но перестановка слотов ломает провода.
- `display_name` — единственный источник подписей; JS/`locales` нет, английской
  версии нет. Синхронизация: `python sync.py Prompt_Logistics` + рестарт.
