# SESSION_MEMORY — Prompt_Logistics

## Состояние
- v2: две ноды в `prompt_logistics.py` — `PromptLogistics` (S) и
  `PromptLogisticsModel` (F). **Все 5 переключателей на S, F без настроек.**
- S: входы `ПрОб`/`ПрМаст`/`INT Prompt` (link-only), переключатели `LLM Prompt`,
  `STYLE Prompt`, `STYLE в LLM`, `INT`, `INT в LLM`; выходы
  `MODEL PROMPT (прямой)` / `LLM PROMPT` / `ДОП к ПрLLM` / `USE LLM`.
- F: входы `ПрLLM` (lazy) / `direct` / `suffix` / `use_llm`; выход `MODEL PROMPT`;
  `base = USE LLM ? ПрLLM : direct`, пустая база → `""`, иначе `base + ДОП`.
- **Ленивый ПрLLM:** `"lazy": True` + `check_lazy_status`; при `USE LLM` OFF
  ветка LLM не запрашивается (Ollama не выполняется). Скрытые `PROMPT`/`UNIQUE_ID`
  + guard на link, иначе `make_input_strong_link` → `NodeInputError`.
- **ПрМаст без дубля:** `master` в suffix только при
  `llm_prompt and style_prompt and not style_in_llm`.
- Тесты: 119 проверок Python + 75 статического аудита — зелёные.
  Живая проба: 45 проверок; lazy-тайминг (KJNodes `Sleep` 4 c):
  OFF 0.02 c, ON 4.03 c.
- Синхронизировано в рабочую копию; сервер после live-пробы остановлен.

## Что не сломать
- Цикл `S → LLM → S` невозможен: ComfyUI 0.41.0 отклоняет `dependency_cycle`
  (HTTP 400). Разрыв цикла — вторая нода F, провода только вперёд.
- **Семантика INT:** `INT в LLM` действует только при включённом `INT`;
  при `INT` OFF интерьерный промпт не участвует нигде.
- `STYLE в LLM` влияет на `LLM PROMPT` и снимает повтор `ПрМаст` в suffix;
  `STYLE Prompt` добавляет `ПрМаст` к итогу только при `not style_in_llm`.
- `ДОП к ПрLLM` наполняется только при `LLM Prompt` ON.
- В режиме LLM пустой `ПрLLM` не заменяется исходным промптом (выход пуст).
- `ПрМаст` не образует промпт сам: при пустых `ПрОб`+`INT` прямой промпт пуст.
- `check_lazy_status` обязан возвращать `[]`, если вход не подключён или
  подключён литералом — иначе падение на валидации графа.
- `display_name` входов/переключателей — единственный источник подписей в Nodes 2.0;
  не переименовывать без обновления тестов, аудита и SPECIFICATION.
- JS-расширения нет намеренно; `WEB_DIRECTORY` не объявлять.
- `sys.dont_write_bytecode = True` в Python-тесте; `py_compile` создаёт
  `__pycache__` — удалять перед `_process/check.py`.
